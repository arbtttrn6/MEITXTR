# MEITXTR
Mass Effect Infiltrator (IronMonkey Studios) strings editor.  
Просмотр строк из `bin` файла `masseffect.bin` из Mass Effect Infiltrator (IronMonkey Studios).  
Gledanje linij teksta iz `bin` fajla `masseffect.bin` iz Mass Effect Infiltrator (IronMonkey Studios).  
arbtttrn6, 2026.  
  
== RU ==  

0) Для чего?  
   0.1) Для просмотра и редактирования строк текста в `Mass Effect Infiltrator` (Android). В основном для просмотра  
1) Как собрать?  
   1.1) Создать папку `build`;  
   1.2) В папке `build` выполнить `cmake ..`;  
   1.3) В папке `build` выполнить `make`;  
2) Как пользоваться?  
   2.1) Для просмотра строк в `bin` файле ввести `MEITXTR masseffect.bin --list`;  
   2.2) Для извлечения всех строк в текстовый файл `txt` ввести `MEITXTR masseffect.bin --dump masseffect.txt`;  
   2.3) Для изменения одной строки по индексу (узнать его можно с помощью команды `--list`) ввести `MEITXTR masseffect.bin --set <index> 'Новая строка' new_masseffect.bin`;  
   2.4) Для пересохранения `bin` файла ввести `MEITXTR masseffect.bin --save new_masseffect.bin`;  
4) Ориентиры  
   3.1) https://ekasiswanto.wordpress.com/2016/01/01/the-sims-freeplays-sbin-file-format/  
  
== ISV ==  

0) Načto?  
   0.1) Zaradi gledanja i redaktovanja linij teksta v `Mass Effect Infiltrator`. Osnovno dlja gledanja.  
1) Kako kompilirovati?  
   1.1) Stvoriti papku-direktoriju `build`;  
   1.2) V direktorije `build` izpolniti `cmake ..`;  
   1.3) V direktorije `build` izpolniti `make`;  
2) Kako upotrebjati?  
   2.1) Dlja gledanja linij v `bin` fajlu vpisati `MEITXTR masseffect.bin --list`;  
   2.2) Dlja izvlečenja vseh linij v tekstovy fajl `txt` vpisati `MEITXTR masseffect.bin --dump masseffect.txt`;  
   2.3) Dlja izmenenja jednoj linije po indeksu (spoznati jego možno je s pomočju komandy `--list`) vpisati `MEITXTR masseffect.bin --set <index> 'Nova linija' new_masseffect.bin`;  
   2.4) Dlja preshranjenja `bin` fajla vpisati `MEITXTR masseffect.bin --save new_masseffect.bin`;  
4) Orientiry   
   3.1) https://ekasiswanto.wordpress.com/2016/01/01/the-sims-freeplays-sbin-file-format/
